# 本地卡牌工坊使用说明

- 项目 The end / emberwatch
- 更新于 2026-11-28（Asia/Shanghai）
- 状态为已实现并通过 Web 验收
- 代码位于 `tools/card-editor-server.cjs`、`tools/card-editor/`、`assets/game/core/content/CardCatalog.ts` 和 `assets/resources/data/cards.json`
- OpenViking 路径为 `viking://~/resources/projects/the-end/docs/card-editor-usage.md`

## 物资卡

打开工坊顶部的「物资卡」，或直接打开[本机物资卡库](http://127.0.0.1:7460/supplies)。左侧可按名称或 ID 搜索，每行显示重量、单张兑换点数和投放状态。点选一张即可改价或调重，也可以点击「＋物资卡」新建，或用复制按钮从已有物资开始。

预览中，卡名居中，下一行显示「价值 X 物资点」。插画右下角砝码里的数字是单张负重。修改重量或兑换值时，卡面会即时更新。填写的物品说明直接排在插画下方，留空时卡名、价值和插画整体居中。

每张物资卡的重量可填 1～30 的整数，兑换值可填 1～999 的整数。「加入搜刮物资池」控制后续投放，奖励权重决定各张卡相对出现的机会。要暂停掉落，可以取消勾选并保留卡牌 ID，已入库的卡仍可兑换。右上角「保存到项目」或 Ctrl+S 会写入同一份卡库。从物资卡页点「试玩游戏」，可以到焦土迷宫的检修暗槽搜刮，再去门前营地仓库查看带回的物资。

名称、价格、文案和掉落权重可以继续调整。改重量后，新拾取的卡按新重量计，已经装进行囊或暂存区的卡保留拾取时的负重。营地仓库按当前单价结算。存档用 ID 识别物资，已有存档引用的卡建议用停用掉落来下架。如果删除了这类卡，游戏会保留原档并提示恢复配置。

## 奖励池编辑 · 2026-11-27

打开工坊顶部「奖励池」，或直接访问 <http://127.0.0.1:7460/?page=rewards>。沿焦土迷宫整卡网格向下滚动，点击卡面切换「已加入」状态，也可筛选全部、已加入或未加入的牌。选完点「保存到项目」。

焦土迷宫在战后和指定搜刮点从当趟的奖励池最多抽三张。把池清空后可正常保存。下一趟遇到这些地点时直接结算物资。旧设置首次读取时合并先前启用的牌，进行中的存档使用出发时保存的名单。

工坊各页的「试玩游戏」均打开焦土迷宫。从奖励池出发会读取刚保存的卡牌配置。工坊与游戏共用 `assets/ashen-labyrinth/interface/` 的插画图集和 `assets/game/core/content/CardCatalog.ts` 的数据校验。

## 2026-11-28 · 迁入焦土迷宫的奖励牌

原先勾选的 23 张普通牌已按原 ID 入池，包括盾矛、盾矛冲阵、盾矛护阵和屠龙宝刀。可从「奖励池」或卡牌右栏逐张勾选。刷新工坊即可查看名单。迷宫从下一趟出发开始使用新名单，进行中的探索从存档读回当趟名单。

合并后的默认名单还包括上游已启用的 9 张拳法招式和辅助牌，共 32 张。可发现的拳法出现在战斗奖励中，收招按当趟战斗解锁。物资单独在「物资卡」页调整投放、重量和兑换价值。

## 启动与试玩

在项目目录执行 `npm run cards`，打开 http://127.0.0.1:7460/ 。服务只在本机监听，终端需要保持运行；可用环境变量 `CARD_EDITOR_PORT` 修改默认端口。

若 Web 构建输出到独立目录，可以用 `CARD_EDITOR_BUILD_DIR` 指定工坊载入的构建。

首次试玩或修改游戏脚本后，先执行 `npm run build:web`。随后通过网页顶部的「试玩游戏」打开真实 COCOS 对局。以后仅修改卡牌数据时，点击「保存并试玩」即可在新对局读取最新数据，不需要反复构建。

已经开始的对局保持原配置，试玩窗口的「重新载入」会开始新对局。独立游戏预览和发布版本使用随构建打包的配置，发布前仍需正常构建。

## 怪物动作 · 2026-11-27

在顶部点「怪物动作」，选择灰灯蛾、叩石螯或垂幡守像。可修改普攻与重击的伤害，在行动顺序里添加、移动和移除「普攻」「蓄势」「重击」。开场从第 1 步执行，末步执行后跳到所设的「循环起点」。默认开场普攻，随后蓄势与重击交替。

点击「保存到项目」后，通过「试玩游戏」开启焦土迷宫。进入对应怪物的战斗时会读取配置。战斗存档带有当时的行动序列、伤害和当前步骤。

## 2026-11-27 · 类型搜索与奖励选项

- 左栏可以按名称、ID 或类型搜索。类型栏可输入「武器」「格挡」等关键词，也可以点开选择。两个搜索栏可同时使用，清空类型栏或选择「全部类型」即可恢复全部类型。
- 编辑焦土迷宫卡牌时，可以在右栏顶部切换「加入随机奖励池」状态。
- 在右栏「基本资料」的插画下拉框中按名称选择，旁边的缩略图会随选项更新。带专用图的卡牌显示「备用插画」。选完用「保存到项目」提交。

## 新增与编辑

1. 点击卡牌库旁的「＋」新增焦土迷宫卡牌，或选中现有牌点击复制按钮。新牌可以在右栏或「奖励池」页加入掉落名单。
2. 填写名称和唯一 ID。ID 为小写字母开头的 2～48 位字母、数字、下划线或短横线，保存后保持稳定。
3. 修改费用、重量、插画、标识色、简述与详细描述。简述显示在卡面。奖励页悬停卡牌时显示详细描述，工坊内可点「查看说明」预览。伤害、格挡等基础效果由配置数值生成。
4. 选择伤害、格挡、修复、抽牌、获得力量或装备效果。装备占用一格或两格，生成牌从下回合开始。
5. 普通牌用「＋」新增。点击卡牌库标题旁的「＋物资卡」可以直接新增物资卡。物资卡不进入初始卡组，设置「兑换物资点」后可加入搜刮奖励池，带回避难所后兑换。
6. 点击「保存到项目」或按 Ctrl+S，也可以直接「保存并试玩」。保存后刷新网页仍能读到修改。

焦土迷宫用体力支付战斗卡费用。获得的战斗卡加入本趟随行牌组。战斗内回复受生命上限限制。

旧版物资卡配置中的临时牌由装备生成，重量为 0。物资牌在编辑器里选择「物资牌」身份，费用与初始数量设为 0，并填写「兑换物资点」。搜刮获得的物资牌会在成功返回避难所后入库。若有新的关键日志，阅读后进入避难所。可以点「兑换全部物资卡」，也可以直接选档位开始下一局。剩余物资点、仓库和已记录的日志随存档保留。出发时使用初始护甲和固定初始战斗卡组。

## 编辑旧版合成配方

1. 在「卡牌编辑」选中材料牌，勾选「可作为合成材料」。可以先创建所需的材料牌和产物牌。
2. 打开「配方编辑」，点击「新建配方」，选择材料、产物及各自的数量。多张卡用「添加材料」或「添加产物」。
3. 点击关系树内的卡名查看各分支。编辑器会指出重复、无效引用、材料资格缺失和循环配方。
4. 点击「保存到项目」。保存后的材料和产物关系可在配方页核对。

## 删除与引用保护

普通牌删除时会一并移出初始卡组与随机奖励池。用于固定搜刮奖励、装备生成或配方的牌，需先更换引用。焦土迷宫奖励池可以保存为空。

基础攻击、基础躲避、旧版现金和系统挥砍的定义保留以支持现有内容。可在允许的字段范围内编辑名称、插画和效果参数。基础牌勾选材料词条后也可被合成消耗。

## 保存与恢复

数据实际写入 `assets/resources/data/cards.json`。保存前校验全部配置并检查修订号，自动备份上一版后原子替换文件；无效数据和冲突不会破坏旧文件。

其他页面或程序更新文件后，保存会提示冲突。先保留自己的修改内容，再「重新载入」并合并，避免覆盖别人的更新。未保存的页面有离开提醒。

备份位于 `temp/card-editor-backups/`，文件名包含时间。恢复前先保留当前 JSON，再选择需要的备份覆盖配置，回到网页重新载入并核对。备份和构建产物不提交到 Git。

`npm test` 执行规则和保存服务测试。合成浏览器验收脚本 `tools/run-recipe-browser-test.cjs` 使用独立测试目录，需要 Web 构建和可用的 Playwright。原卡牌编辑器验收驱动继续保留在 `tools/browser-card-editor.js.txt`。

## 旧版盾矛路线记录 · 2026-11-25

本项目已经接入盾矛三层合成路线。装备卡的「每回合生成牌」字段可以填写多个临时牌 ID，并使用逗号分隔。装备卡可设置占用 1 或 2 个武器槽。普通战斗牌仍然可以通过「可作为合成材料」词条加入配方材料。

奖励池中的材料卡支持「奖励权重」。合成路线会在完成上一层后临时提高下一层材料的抽取权重，获得该材料或本次探索结束后恢复普通权重。配方产物不会自动进入随机奖励池。

盾矛配套牌属于配方产物，不进入随机奖励池。盾矛的蓄势、复合效果和配套牌强化由游戏规则层执行，编辑器中的补充说明用于卡面展示。第一层材料的互相引导权重和后续层材料权重也由规则层保存，材料领取后恢复普通权重。

## 旧版屠龙宝刀路线记录 · 2026-11-25

- 搜索「磨刀石」「龙血」「屠龙宝刀」可修改试玩数值与名称。磨刀石选用「获得力量」，龙血选用回复效果，两者都勾选了「每张每场限用一次」。
- 装备牌的「装备力量」在装备时生效。攻击牌可在「攻击段数」填写命中次数，效果数值为每段的基础伤害。奖励权重接受小数，可独立调节稀有材料的出现概率。
- 三种进阶挥砍是独立临时牌。武器的「每回合生成牌」填写对应的临时牌 ID。修改卡名时保留 ID，配方和存档用 ID 识别卡牌。

## 焦土迷宫发现牌组 · 2026-11-22

点击顶部「发现牌组」，可勾选共用配合、蓄压倍率和快速暂缓。三组初始全选。发现池为所选牌的去重并集，同一张牌编入两个勾选组仍只占一个候选。全不选时，战后或搜刮直接收下物资并继续。选中一张焦土迷宫牌时，可在右侧调整它所属的发现牌组。

点「保存到项目」再打开「试玩游戏」，原生游戏新局按网页配置读取牌池。玩家本趟开启时的发现池与已出现的候选随存档恢复。游戏发行包会随构建带上已保存的配置。现有盐原进度继续使用对应章节的牌面数据和规则。

工坊和游戏使用同一插画图集，位于 `assets/ashen-labyrinth/interface/`。共用数据校验位于 `assets/game/core/content/CardCatalog.ts`。

卡牌编辑页的「试玩游戏」进入焦土迷宫。配方编辑页的同一按钮进入原有合成探索。勾选「试玩时解锁地图合成」也会进入合成探索，并在测试对局启用地图合成。

## 启动与试玩

在项目目录执行 `npm run cards`，打开 http://127.0.0.1:7460/ 。服务只在本机监听，终端需要保持运行；可用环境变量 `CARD_EDITOR_PORT` 修改默认端口。

首次试玩或修改游戏脚本后，先执行 `npm run build:web`。随后通过网页顶部的「试玩游戏」打开真实 COCOS 对局。以后仅修改卡牌数据时，点击「保存并试玩」即可在新对局读取最新数据，不需要反复构建。

已经开始的对局保持原配置，试玩窗口的「重新载入」会开始新对局。独立游戏预览和发布版本使用随构建打包的配置，发布前仍需正常构建。

## 新增与编辑

1. 点击卡牌库旁的「＋」新增，或选中现有牌点击复制按钮。
2. 填写名称和唯一 ID。ID 为小写字母开头的 2～48 位字母、数字、下划线或短横线，保存后保持稳定。
3. 修改费用、重量、现有插画、标识色与补充说明。主要效果说明由配置数值自动生成，卡名使用标识色衍生的可读深色字。
4. 选择伤害、格挡、修复，或装备生成指定临时牌的效果。装备从下回合起生效，仍占用唯一武器槽。
5. 普通牌用「＋」新增。点击卡牌库标题旁的「＋物资卡」可以直接新增物资卡。物资卡不进入初始卡组，设置「兑换物资点」后可加入搜刮奖励池，带回避难所后兑换。
6. 点击「保存到项目」或按 Ctrl+S，也可以直接「保存并试玩」。保存后刷新网页仍能读到修改。

合成探索用体力支付战斗卡费用。固定初始卡组和本局获得的战斗卡独立于行囊负重。旧存档按原章节继续探索。战斗内的修复卡仍受护甲上限和感染临界限制。

临时牌由装备生成，重量为 0。物资牌在编辑器里选择「物资牌」身份，费用与初始数量设为 0，并填写「兑换物资点」。搜刮获得的物资牌会在成功返回避难所后入库。若有新的关键日志，阅读后进入避难所。可以点「兑换全部物资卡」，也可以直接选档位开始下一局。剩余物资点、仓库和已记录的日志随存档保留。出发时使用初始护甲和固定初始战斗卡组。

## 配置合成配方

1. 在「卡牌编辑」选中材料牌，勾选「可作为合成材料」。可以先创建所需的材料牌和产物牌。
2. 打开「配方编辑」，点击「新建配方」，选择材料、产物及各自的数量。多张卡用「添加材料」或「添加产物」。
3. 点击关系树内的卡名查看各分支。编辑器会指出重复、无效引用、材料资格缺失和循环配方。
4. 点击「保存到项目」。通过「试玩游戏」进入营地，或先勾选「试玩时解锁地图合成」再从地图打开配方表。试玩从新一局开始。

## 删除与引用保护

普通牌删除时会一并移出初始卡组与随机奖励池。用于固定搜刮奖励、装备生成或配方的牌，需先更换引用。奖励池至少保留一张普通牌。

基础攻击、基础躲避、旧版现金和系统挥砍的定义保留以支持现有内容。可在允许的字段范围内编辑名称、插画和效果参数。基础牌勾选材料词条后也可被合成消耗。

## 保存与恢复

数据实际写入 `assets/resources/data/cards.json`。保存前校验全部配置并检查修订号，自动备份上一版后原子替换文件；无效数据和冲突不会破坏旧文件。

其他页面或程序更新文件后，保存会提示冲突。先保留自己的修改内容，再「重新载入」并合并，避免覆盖别人的更新。未保存的页面有离开提醒。

备份位于 `temp/card-editor-backups/`，文件名包含时间。恢复前先保留当前 JSON，再选择需要的备份覆盖配置，回到网页重新载入并核对。备份和构建产物不提交到 Git。

## 检查

`npm test` 执行规则和保存服务测试。合成浏览器验收脚本 `tools/run-recipe-browser-test.cjs` 使用独立测试目录，需要 Web 构建和可用的 Playwright。原卡牌编辑器验收驱动继续保留在 `tools/browser-card-editor.js.txt`。

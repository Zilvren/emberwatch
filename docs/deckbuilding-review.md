# The end · 退潮盐原镇静构筑评审

2026-11-18 · Asia/Shanghai · 旧构筑评审记录

本评审适用于早先的多牌构筑草案。当前试稿以 `docs/designs/deckbuilding-system.md` 中的三张镇静牌和单一暂缓门槛为准。

> **奖励前提更正（2026-11-18）**　用户确认一趟探索里有多次选牌机会。下文两次、三次是曾建议的节点试投放例，实际出现的次数与时点随奖励设计确定。评价慢线以实际拿牌与兑现的过程为准。

适用范围为退潮盐原、12 张起始牌的设计稿和 19 张镇静候选牌。依据为 `docs/designs/deckbuilding-system.md`，地图、抽牌和现有攻击牌参考 `assets/game/core/content/GameScenario.ts`、`assets/game/core/systems/CombatRules.ts` 和 `assets/resources/data/cards.json`。OpenViking 归档 URI 为 `viking://~/resources/projects/the-end/docs/deckbuilding-review.md`。

## 评审结论

两条路线都值得保留。倍率线要跨回合蓄层，等校准和攻击牌同时到手，收益是一记高伤害。快线花掉层数买一个完整回合，要根据怪物意图决定何时触发。普通层可存，临时层当回合使用。两条路线可以共用入口牌，也可以在战斗中按当前手牌和怪物意图换一种方式用掉层数。

现稿最大的风险是**短路线成型机会少、额外回合整体收益高、倍率和状态结算有未定义的边界**。19 张适合作为候选库。盐原首轮从小卡池验证两个闭环，费用、叠层量和伤害再根据实际战斗调。

## 优先修正

### P1 · 先保证闸轮前有机会成型

当时的试摆示例只在旧水标、转运舱各放一次奖励，闸脊线再加巡标机的战后奖励，才会得到两次或三次选牌。在那个示例里，两次单选凑不齐三个独立环节。用户已确认一趟有多次选牌机会，实际地图需要按投放节奏评估。

以下两张的组合可以作为低发现量时的起步对照。完整构筑按实际拿牌走势与战斗长度评估。

- **倍率线用扩容阀和蓄压校准。** 扩容阀本身承担普通叠层。可以先试让校准在未到门槛时也有普通叠层的用途，达到门槛才变成倍率准备。这样两张都能在成型前行动，逆相探针变成补强。需要重点试玩两张牌能否在闸轮战结束前完成一次倍率攻击。
- **快线用一张普通叠层牌和急卸阀。** 最低配可以用起始牌在额外回合打伤害，抢隙猛击是额外回合的强化。旧水标可以给能独立使用的入口牌，后续选牌根据已拿到的入口给对应核心或通用选项。预挂夹、回压护腕等窄用途牌放到已有触发手段之后。

一个只说明风险的算例。若 19 种牌每处均匀抽三张、三处独立，玩家固定想集齐三种指定牌，每次优先拿尚缺的一种，三处都拿到需要牌的概率约 2%。实际候选池建议分组，当前草稿也没有这样的均匀投放规则。这个算例用来说明关键牌依赖会放大稀释，不能当成实装掉率。

当前运行版仍用 20 张基础牌，盐原发现发生在战斗开场或失压时。当前地图和敌人可作参照。实施这份构筑前，要把试验候选放到设计使用的搜刮和战后入口。

### P1 · 快线买到的是完整回合，收益包含抽牌和发振

当前闸轮的常规顺序是普通攻击、准备、重击。若在闸轮的意图为准备时触发暂缓，这次准备会在额外回合结束时执行。玩家接着又有一次常规行动，之后才结算重击。准备当回合、额外回合、接重击前的常规回合都能先出牌。若推迟的是已经蓄好的重击，则要在额外回合结束之前解决敌人或重新铺格挡。两个时点均可以有价值，实测要比较玩家是否总会选同一个。

建议首测守住两个时序条件。从零起手时先让怪物完成一次实际行动，再允许急卸阀提前触发。得益于暂缓的额外回合里，怪物完成原动作前锁住再次叠层。这仍允许比自动门槛更早触发，也让额外回合保有完整刷新。可通过让提前门槛高于空场同回合可施加量实现第一条，等有起始层数的道具时再重新验证。

另一个风险是额外回合抓到的都是叠层与校准工具。按这份起始牌表，基础主动攻击是三张压掌加一张沉锚。19 张新候选中，直接出手造成伤害的是测隙击、抢隙猛击、折返击，另有倍率和回流盾反击。用太多工具稀释后，快线可能拿到空转回合。首测先用备压匣把下一张进攻牌排到顶，观察多少额外回合能确实用于抢攻或防守，再决定是否需要预挂夹。

### P1 · 倍率边界与校准资格要在攻击时确认

稿中的「原本应造成的伤害」可能包含牌面以外的条件加伤。现有追波是基础伤害 2，若本回合先出过攻击再加 4。当镇静层数为 L，若全额相乘是 `6 × L`，若只有基础伤害相乘则是 `2 × L + 4`。当前闸轮是 26 生命。单看现有沉锚 5 点基础伤害，已足以在 6 层做出 30 伤害。这是牌值推演，不是本轮建议的叠层门槛。

建议保留一次明确的「选一击做乘法」，首测以**牌面基础伤害乘层数，条件加伤在乘算之后再结算**，同时保留沉锚这类牌的高层爆发。这样输出上限更容易预期，后续有追波、返压或折返击也容易讲清楚。

校准资格建议在攻击结算前复核。例子是先校准，又用泄压护片转掉一些临时层，导致总层数落到门槛以下。此时按普通攻击结算，层数照常保留。若仍达门槛，读取当下普通和临时层总和，结算这次攻击并消耗读到的旧层，再处理攻击牌自带的新叠层。这个顺序也覆盖蓄好后先打测隙击的情况。

抽牌也会限制这一击。用试摆示例的 15 张牌，每次抽 5、首轮不额外过牌和重排，蓄压校准和唯一一张沉锚在同一手出现的概率约 29%。若允许任意一张基础攻击配校准，按四张基础攻击算，这个同手概率约 79%。这里仅比较同手，尚未要求那一手同时达到倍率门槛。试玩应让压掌兑现也有意义，再看宏观伤害是否合理。

### P1 · 把叠层、暂缓和反击放到确定的结算顺序

- 扩容阀先抬门槛，再施加普通层。已安排的暂缓从当时的怪物意图锁定，后续只结算一次。把普通层换类型、临时层期满或随后抬高门槛，都不撤销已经安排的动作。
- 止回阀只能拦截本来合法的叠层。建议先扣本回合的合法施加额度，再将其中一部分施加、另一部分转成格挡。若拦下的层数完全不占额度，重复打出拦截和叠层牌就能让同一份施加额度多次换格挡。急卸阀的主动触发仍按当时总层数判断。
- 从安排暂缓到怪物执行原动作，已经锁定的层数只用于暂缓结算。结束当前回合时清空两种镇静，照常清格挡，额外回合重新准备格挡。怪物在此前被击败时按胜利结算。
- 回压护腕关注一次倍率消耗事件。回流盾关注一次实际发生的被推迟攻击。建议首测同类效果在同一事件只响应一次，整次攻击完全格挡才反击。原意图是准备时，回流盾只提供自身格挡。
- 预挂夹要移走原牌实例，提供每场战斗一个槽。取回、替换、战斗结束都归还到明确牌区。让战斗界面显示普通层、临时层、已推迟的意图以及被夹住的牌，玩家才能按看到的牌序计划。

| 逆相探针 | 首测 | 纯普通叠层，是衡量混合牌要付多少体力的参照。 |
| 阻尼片 | 首测 | 格挡与叠层同时有用，适合第一场只有入口牌时使用。调值时要与纯防御、纯叠层区分。 |
| 短效脉冲 | 首测 | 两条路线都能当回合补层，付费与层数到期给它清楚的代价。 |
| 测隙击 | 后续 | 准备回合多一个临时收益，时机清楚。观察伤害与叠层兼有后是否压过通用攻击。 |
| 盐壳护板 | 后续 | 让保留高层时更安全。先护板后消耗的顺序有价值，额外回合清层后通常只能获得基础格挡。 |
| 回线盒 | 后续 | 解决抽不到叠层牌，找的是弃牌区的实体牌。若首测因牌序频繁晚于战斗收尾，优先加这张。 |
| 备压匣 | 首测 | 提前排好下一抽。玩家用开匣等效果还可继续抽牌，想确保留给额外回合时应最后打。 |
| 封样管 | 后续 | 临时层转普通给了跨回合的选择。转化仍保持总层数，留在牌池时需有消耗或限量，否则临时牌的到期代价会被弱化。 |
| 泄压护片 | 后续 | 让即将到期的层数有防守价值，只在仍可支配层数时使用。试玩与直接使用折光屏相比，多出牌的一步是否有用。 |
| 扩容阀 | 首测 | 高层窗口的入口。首次提高，后续依然可施层，避免每次抓回都变成只处理本场一次的牌。 |
| 蓄压校准 | 首测 | 让层数变成一击。优先定攻击前复核、基础伤害范围和准备时的普通用途。 |
| 止回阀 | 后续 | 允许手动停在自动门槛前，给高线操作空间。先定截走层数的额度与主动触发优先级。 |
| 回压护腕 | 后续 | 倍率击未能终结战斗时能补格挡。格挡仍要为此花一张牌，并且同次消耗只领一次。 |
| 急卸阀 | 首测 | 快线有独立入口。是否提前用应由敌意图决定，先测从零起手的最早触发。 |
| 抢隙猛击 | 首测 | 一张直观的额外回合收益，平时也能出手。 |
| 回稳屏 | 后续 | 额外回合补牌与防御的选项。先看一整个额外回合已给多少抽牌收益。 |
| 预挂夹 | 后续 | 比顶牌留得更久，代价是提前把攻击移出常规循环。等有证据表明快线常缺输出再引入一格保留。 |
| 折返击 | 后续 | 给额外回合的攻击排序奖励。只读取上一张攻击的牌面基础伤害，结算容易读懂。 |
| 回流盾 | 后续 | 赋予推迟重击的独立理由。完全挡住才反击，正好能和纯抢攻的额外回合拉开取舍。 |

## 首轮验证与证据范围

## 16:25 双路线旧稿的复盘

本节按聊天中贴出的 16:25 牌效评审。那一稿的扩容阀只写提高上限，急卸阀只写增加临时镇静。此前评审用过补过部分条件的设计稿，两版的牌效需要分别读。用户后来明确，普通攻防牌不叠层，带镇静的牌即时攻防较弱。两条路线的比较按这项前提。当前的镇静启用条件见构筑稿。

### 两条路线各自卡在哪里

| 路线 | 玩家想做的取舍 | 牌稿能确认的缺口 |
| --- | --- | --- |
| 高层倍率 | 用较弱的牌攒层，决定现在换一记高伤，还是继续蓄层争取更大的收益。 | 16:25 稿的扩容阀只写提高上限。若自动门槛仍是原值，到线就会预约暂缓，因此还需明确提高上限时是否一起改变触发线。该版要演示高层倍率，至少要有一张叠层来源、扩容阀和蓄压校准，最后还要在层数可用时同手接上攻击。沉锚等基础攻击可以承担最后那个动作。 |
| 快速暂缓 | 少等一段时间，选一个想推迟的敌方动作，用换来的手牌进攻或接伤。 | 16:25 稿的急卸阀只写加临时层，可能帮玩家较早凑到同一门槛，但没有写独立的提前触发资格。真正暂缓一次后，普通攻防就能用额外回合。若把抢隙猛击的额外伤害当作这条路线的必要收益，它还必须在额外回合拿到；手里的猛击随常规弃牌处理，预挂夹于是成了专门修这份牌序配合的额外环节。 |

旧试摆里每处只选一张，干潮沟两次、闸脊线三次。当前设计允许一趟有多次选牌。评审倍率线应按实际奖励核对玩家何时拿到叠层、扩容和校准，以及何时能把投入兑现。快线可以先验证普通攻防兑现，再单独看费用是否足以支持专属收益牌。

### 不落地可以验证为什么

在规则层，先定扩容是否改变触发线、急卸怎么提前，以及已经预约的层数能否供倍率使用。Bogay 明确说过需要回头查蓄压校准，这提供了阅读上的一个具体证据。重复暂缓和清格挡先后是可以测试的结算风险。这些反馈并没有替另一位同事说明他个人否定的是哪一步。

在玩法层，把取舍写到具体回合。比如扩容、校准和攻击已到位时，玩家应能看见现在用层数换伤与继续蓄层延后攻击的不同代价。若抽牌和自动触发大多已替他决定，设了两种终点也未必会产生两种打法。用地图实际能给的牌先验证各自能否进场和触发，再查之前为了叠层放弃的即时攻防有没有回报。只展示拿齐配套后的连招无法回答这个问题。

现有单门槛稿的同敌同手纸面推演展示了临满时，玩家能选择现在稳挡，或先压血再把同一记重击推到下一手之后。这个算例支持暂缓存在一种有意义的潜在选择，范围仅为一次接近叠满的局面。两条旧路线的通常成型时机与全场取舍仍待试玩。

## 附件旧稿：只看牌效的可玩性评审

2026-11-18 · 纸面评审。依据本次提供的 `deckbuilding-system.md`，包含封样管和泄压护片。同一趟探索有多次选牌机会。本节不调整数值，也不改变当前构筑稿的启用决定。

- **倍率线缺少清楚的兑现窗口。** 扩容阀只写提高上限，自动暂缓由另一条门槛触发。如果只抬容纳上限，玩家想再叠一层留给蓄压校准时，可能已经预约了暂缓。门槛前照样可以打倍率，但高层倍率路线要先说清何时能继续攒、何时能自己花。校准还要在有可用层数和攻击牌的同一回合打出；拿到扩容阀本身并不会解决眼前的攻防。
- **临时层和两条路线没有清楚的关系。** 急卸阀可以冲暂缓，也能在层数尚可用时给当回合的倍率加层；封样管把快叠的层数留下，泄压护片让它当回合换格挡。跨路线共用可以带来混搭，纸面问题在于还没有说清玩家在什么局面愿意快用、转存或继续攒普通层。效果越多，越需要有不同的使用理由。
- **快线的额外配合受出牌顺序限制。** 额外回合会重抽。提前摸到抢隙猛击或回稳屏时可以按基础效果打，想吃强化就要留牌、安排抽牌或碰到合适的下一手。回线盒、预挂夹本身可作通用准备；若主要用来把专用牌送到正确回合，就增加了出牌步骤。回流盾有不同的潜力：如果玩家为了挡住再反击而主动选择推迟一次攻击，它确实能改变暂缓时机。
- **若干选牌缺少即时用途。** 测隙击和阻尼片能处理当前攻防，纯叠层、纯扩容和层数转换需要已有条件才有回报。多次选牌有助于补配合，仍要评估中途拿到、尚未配齐时是否值得选和打。起手表里两种纯伤害牌、两种纯格挡牌按效果分别同质，更多的战术差异要等新牌加入。

最值得保留的对局选择是：面对一记重击，现在用普通格挡接下来，还是叠满镇静，先压血再靠一手新牌找斩杀或重新防守。试玩时可给同一手牌换「准备」与「攻击」的敌人意图，看玩家是否改变出牌顺序、愿不愿意推迟触发。没配齐专用牌时也做一遍。附件能说明这些条件和风险，尚不能证明实际战斗缺乏乐趣。

## 11 月 19 日附件：起手叠层与双路线复评

2026-11-19 · 纸面评审。依据本次上传的《退潮盐原卡组构筑》附件；沿用一趟探索有多次选牌机会的前提。以下是牌效建议，适用该附件草案，当前职业阶段预留稿未变更。

- **起手叠层改善了构筑前半段。** 沉锚和折光屏分别靠攻击和格挡叠层，压掌和滑步保留纯攻防。玩家第一场就能尝试镇静，随后选到蓄压校准或抢隙猛击，牌组已有为它们攒层的入口。阻尼片、测隙击可以提高叠层牌的出现频率；若希望选牌带来新打法，还需要看各张牌的用途是否有区别。附件删去封样管后，正文的层数转换说明也可核对是否仍有对应效果。
- **「怪物镇静时」决定快线奖励什么。** 抢隙猛击、回稳屏和回流盾改用这个条件。若指身上有镇静层，沉锚叠一层就能开启回稳屏和抢隙猛击的强化，即使从未暂缓；这样的效果适合做两线共用配合。若希望奖励推进到额外回合，建议写「怪物的行动已暂缓」：从安排暂缓起，到原动作结算完为止。叠满的同一手可以接猛击，额外回合清掉层数后也仍能强化。回流盾的反击在实际挡住那次延后的攻击时结算。急卸阀只写临时叠层，可帮助冲到同一门槛，附件还没有单独的提前触发牌。那张阈值触发时抽牌的能力牌，宜明确在安排暂缓的当下抽牌，让玩家还能调整本回合的后续出牌。
- **扩容仍需说明是否改变触发线。** 写成能力牌说明了持续类型，未说明「上限」是否也是自动暂缓的门槛。仅抬容量时，跨过原门槛仍会安排暂缓，倍率可在触发前打出，却无法靠扩容攒过原门槛。若要让玩家为高倍率主动蓄层，建议写清扩容一并抬高自动暂缓门槛；同一批层数一旦分配给暂缓，就不再供校准使用。临时层仍能在触发前喂给校准；这种混搭可以保留，重点是何时花层以及放弃什么。
- **先推演折光屏碰到重击的临界一手。** 若沿用正常换回合清格挡，折光屏叠满时，这回合拿到的格挡会在延后的重击前清掉。玩家可以用普通格挡现在接住、把镇静留到之后，也可以用沉锚等牌叠满，腾出时间找斩杀或换一手防御。这个取舍值得保留，但要让玩家看出折光屏触发暂缓时无法靠本回合的格挡接同一记重击。用同一手再换成敌人准备的意图，检查玩家是否因此改变打法。

牌表核对：有填写数量的行合计十二张，「下一张技能牌消耗为 0」一行未填名称和数量；若也放一张，合计十三张。回合结算参照 `assets/game/core/systems/CombatRules.ts`，这里只核对常规格挡清空，未验证附件的新牌效在游戏里的表现。

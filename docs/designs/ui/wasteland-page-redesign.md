## 已否决的侧栏版本

左侧改为贯穿全高的生存装备栏，日期、物资、护甲、背包和菜单纵向排列。中央保留场景、角色与地图；战斗把敌人意图放在上方，状态读数置于角色下方，底部形成独立的手牌整理台，牌堆与结束回合操作各有固定位置。

日志页使用角色画面与出发记录组成的双区；地图围绕可读的分支路线重新布置；奖励、营地和结算改成装备台式的分区，而非沿用旧界面的坐标。背包改为六个装备格，说明、重量、战斗资格和操作在格内分层。帮助、记录和确认窗口同步到新的材质与主内容区。

用户指出这一版像网页后台和 PPT，完全没有沉浸感、游戏感。该意见优先于先前的组件研究顺序；上述侧栏和大色块不是已确认方案。16 份 UI/场景资源已回滚至改版前基线，否决稿保留于 temp/wasteland-layout-rejected/，原基线位于 temp/wasteland-layout-before/。

## 当前场景优先评审稿

完整场景占据画面，角色和敌人成为视觉中心；固定侧栏、大片色块和窗口化战斗区已经撤除。资源与菜单以贴边的透明 HUD 呈现，角色状态贴近场景位置，手牌以扇形位于底部，结束回合改为独立的回合操作钮。人物保持原造型和原比例，只调整战斗站位。

环境层只加入微弱的远景运动与少量尘埃；命中时的短反馈由原来的命中事件触发，不参与伤害结算。减少动态效果偏好下停用环境移动和位移反馈。场景柔和边缘遮光为文字提供对比，通知去掉遮挡场景的大横条。

assets/game/presentation/effects/SceneAtmosphere.ts、primitives/SceneShade.ts 负责上述表现，GameDirector 只在已有 effect 调用处触发表现。布局资源由 tools/build-immersive-layout.cjs 明确编写，普通构建不会执行该工具。主游戏仍是 Pink/Cocos 引擎，不是 HTML 组件模拟的游戏界面。

临时战斗预览：http://127.0.0.1:7457/?seed=17&save=off&preview=encounter&design=immersive-02 。入口通过常规 GameSession 命令到达首场战斗，不直接篡改存档；仅在显式 seed 且不保存的预览模式启用。普通游戏入口不跳过流程。

实机录屏为 output/playwright/immersive-battle.webm；拖牌攻击、防御与敌方回合已实际操作验证。该记录证明可运行与命令行为，不证明美术已经定稿。进一步视觉判断等待用户对完整战斗画面的反馈。

## 用户最新评审优先级：人物、背景与材质的协调

用户在完整战斗预览后明确选择先处理人物、背景和材质的协调。当前人物沿用 08 细描边原画和原显示比例；背景由像素化夕阳场景改为同线条、同色块语言的手绘废土街道、庇护所外景和室内。灰橄榄、浅土黄与淡棕色配合中性漫射光，避免人物与背景来自不同美术系统。

战斗使用近景建筑与共享地面基线校准尺度，通过场景实例覆盖调整接触阴影位置，不重画或缩放人物。牌堆改为原生细线旧纸卡堆，手牌纸色按同一旧帆布色调整；背包图标复用手牌的手绘物品，取消混用像素图标。像素原图保留，不覆盖其字节。

新资源：assets/resources/art/field-sketch-street-v1.png、field-sketch-depot-v1.png、field-sketch-shelter-v1.png；对应原生图集与 PNG 同目录。背景由内置 image_gen 编辑生成，提示词与来源见 coherence-backgrounds.prompt.json。当前仍为美术评审稿。

## 视觉方向

深灰绿金属、旧帆布、灰橄榄和低饱和土黄。关键操作用磨损黄铜色，危险操作用锈红色。固定缺口、细线与角部结构提供废土设备感；正文保持清晰，不使用闪烁或霓虹装饰。既有简笔物品画放在浅帆布衬底上，保持辨识度。

底层继续复用已验证的原生输入、焦点、只读状态和命令分层。新布局直接写入 Scene / Prefab；资源编写工具不在普通构建时自动重生成。旧组件研究场景保留为历史和局部回归样例，不再限制这一版的整体布局。

## 验收

在真实 Cocos 主游戏检查八个现有阶段与覆盖层：信息层级、角色和标签遮挡、手牌悬停与拖动、地图路线、奖励领取、背包分页、丢弃确认、修复风险和最终每日消耗。截图以实际引擎画面为准，技术通过不代替美术评审。

## 2026-11-15 完整作品复审修订

状态：现有教学流程的交互与视觉修订已实施；正式多日系统仍为后续设计，整体美术认可继续保留给用户。

背包从旧紫色像素边框改为与手牌一致的旧纸、细线与手绘物品，补齐每件物品的效果摘要和不可操作原因。地图保留现有路线坐标和规则，补充有深色衬线的路线连接。实色主按钮取消会糊住字形的场景描边，透明 HUD 的文字仍有对比保护。08 原画、演员预制体和显示比例没有重新生成或缩放。

奖励页在部分领取前说明实际可装入量与放弃量，满背包时不消耗奖励；离开余下奖励和重玩教学均需确认。确认窗口的关闭图标与底部取消按钮使用独立标识，避免动态文案挤坏图标。战斗显示格挡后的实际受伤预告、武器首次生成时点，并补充长按读牌提示。上述修订不改变出牌费用、敌人数值、每日消耗顺序或风险后仍可修复的规则。

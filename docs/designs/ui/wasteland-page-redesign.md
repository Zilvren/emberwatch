# The end 整体页面与废土 UI 改版

## 2026-11-28 · 技能按需查看与仓库出售

《The end》在 `cyb/202611` 按玩家反馈调整营地。技能树打开时，蚀刻图上只有印记、名称和已有的学习标记。点印记或用键盘激活节点，右手边才出现费用、效果和学习按钮。再次点同一印记可收起说明。前置未满足或物资不足时，按钮显示原因。离开再回来时，地图重新收起说明，已经学会的印记仍在。

物资仓库每页最多陈列六种物资。点一叠查看卡片，再点「出售一张」按卡片标价获得物资点。卖空后撤下该货位，最后一页清空会回到上一页。储备空间不足时暂时停用出售按钮。页码仅在需要翻页时出现，空仓只显示「尚未存入物资卡」。守门人负责遗物兑换和交谈。

技能图和仓库使用原生 `CampSkillsScreen.prefab`、`CampWarehouseScreen.prefab`。交互见 `assets/game/presentation/ui/UiActionRouter.ts`，库存扣除与物资点到账仍由 `assets/game/core/systems/ShelterRules.ts` 处理。

## 2026-11-28 · 营地陈列与迷宫技能图

《The end》已在 `cyb/202611` 实装。商店、仓库和技能页以实际可见窗口为边界。标题和返回营地沿顶边排版。柜台下方保留交谈，库存或商品跨页时显示翻页。商店与仓库的陈列区在宽屏与详情并排，在窄屏位于详情上方。物件、价签和输入区域共用位置，改变窗口尺寸会保留当前页与选中项。

守门人商店从遗物目录取货。每页最多六件，按实际宽度摆两列或三列。点实物或架签查看余额、效果和兑换条件，确认兑换才扣点。仓库沿用物资卡原画、卡框和同类堆叠。架签显示名称与张数，点卡可读描述、查看售价并出售一张，翻页可看后续种类。新增遗物沿用同一件货位模板，缺少专属插画时使用通用物件图。

工作台铺开一张画有回廊、城门和庭院的蚀刻图。「扎稳脚步」「固守」「先机」分别以足迹、盾纹、眼纹标出。点印记在右侧查看费用与效果，已学会的节点留下印章，分支刻线随学习进度亮起。细长竖屏把图转向展开，文字始终正向。技能数值与学习条件继续读取 `assets/game/core/content/GateCamp.ts`。页面布局见 `assets/game/presentation/ui/CampRoomLayout.ts`，原生装配见 `tools/author-gate-camp.cjs`。

## 2026-11-28 · 守门人的遗物商店

## 2026-11-28 · 门前营地与三个独立页面

《The end》在 `cyb/202611` 实装。点击左桌打开技能树，点击右箱打开物资仓库，点击篝火左侧木墩上的书打开任务日志。这三个入口各自切换整屏，进入后营地绘景与热点退场，柴火背景声连续播放。「返回营地」和 Escape 都能回到营地。技能、交易、入场仍由各自的规则命令处理，浏览页面不写入存档。

仓库陈列已入库的物资卡。同种物资合并显示数量，每页最多六种。点卡可在详情牌上查看并按张出售，空仓保留一处提示。悬停、按下或用键盘选中手记时，只有书页提亮。点书后旧皮面手记从木墩的位置放大，纸页绕书脊翻开。左页印营地日期，右页留给当前任务。任务系统尚未实装，当前显示「暂无进行中的任务」。关键剧情日志仍按既有节点触发。实现见 `assets/prefabs/screens/CampSkillsScreen.prefab`、`CampWarehouseScreen.prefab`、`CampTaskJournalScreen.prefab` 及 `assets/game/presentation/ui/UiActionRouter.ts`。

《The end》已实装，场景字迹待玩家试玩。石门透光的门缝穿过屏幕正中心，「进入」与「迷宫」分刻在中点两旁的石面，点屏幕中心即可查看入场补给。技能树写在左手工作台的旧箱上，仓库写在右手木箱上，守门人的摊布写「遗物商店」，篝火旁的木墩上摊着一本可翻阅的日志。点字迹或对应实物都能进入。悬停或键盘选中时，门缝、桌面、摊位、木箱或书页会局部受光。按住移出后松开可取消。石楣导航只在实际作战时出现。Pink 简易浏览器的「焦点锁」指示器在项目工作区关闭。

点击石门选择入场补给，确认后才扣费。仓库用于查看已入库的物资卡。点选仓库里的卡堆即可按单张标价出售。

玩家确认在营地花现有物资学习永久技能。左桌打开蚀刻技能图，点印记查看费用与效果，点学习时扣费。当前入门「扎稳脚步」耗 2 点，每战起始获得 1 格挡。学会后可选「固守」耗 6 点，额外获得 2 起始格挡，或「先机」耗 8 点，起手多抽 1 张。两个分支可以先后习得。每项只购一次，返营、失败重试和读档均保留，重开新档清空。技能名称、数值与价格属于试玩配置。每次进入迷宫都生成当趟的初始牌组并恢复初始血量。上趟获得的战斗牌在返营时离开。规则与存档见 `assets/game/core/content/GateCamp.ts`、`assets/game/core/state/GameState.ts` 及 `CombatRules.ts`。

玩家认可当前混音。营地一出现就准备并启动背景声，木柴声缓缓淡入，底下有轻风和偶尔的篷布摩擦。进入任一面板都延续同一段炉火。手记可切换静音，离营停声，返营按当前设置淡入。首次直接访问遇到浏览器的自动播放限制时，已排好的声音在页面收到有效点击、触摸或按键后接续。从工坊点「试玩」进入可同时取得播放许可。开启减少动态效果后，五个地点保留静态选中反馈。原生界面与声音入口见 `GateCampScreen.prefab`、`CampStationPopup.prefab`、`CampSkillTree.ts` 和 `GameAudio.ts`。

## 2026-11-28 · 战斗界面与物资背包

《The end》已确认的界面原则是「一目了然，加美术设计」。数值放在它描述的对象上。常态战斗只显示当前决策需要的信息，操作说明收在帮助与按需查看的详情里。

贴近窗口上沿的石楣透出背景明暗，细窄暖边将导航与石廊墙体区分开。左侧显示带尖顶和亮门洞的城堡、「第 N 天」及物资箱，正中显示「第 N 回合」。右边依次是牌组、本场物资背包、地图和设置。旧章节按条件增加配方册。双方血条内居中显示当前／最大生命，玩家血条左端的青灰盾牌显示当前格挡。

能量石盘只显示当前／最大能量。手牌区上方留给选牌与选敌。抽牌背是朝光上行的冷灰台阶，弃牌背是通向暮色的下行拱廊，牌面下端显示堆数。暖色刻边石牌上写「结束回合」，额外回合可用时显示「进入额外回合」。

物资背包是本场携带物资卡的只读视图。空包显示敞开的亚麻行囊和「暂无物资卡」。面板宽度随卡数调整，每页最多三项，最后一行居中。仓库存量与顶部物资点数各自独立。背包、牌堆与设置共用柔和的灰紫底板和石质切角。

用户确认移除「本日行动记录」。出牌、结算和探索不再写行动流水。读取旧存档会舍弃该字段。营地篝火仍可回看按节点解锁的剧情，存档保存其文案 ID、发生天数和已读状态。规则实现见 `assets/game/core/state/GameState.ts` 和 `assets/game/core/systems/JournalRules.ts`。

灰灯蛾、叩石螯与垂幡守像各自在原生预制体里标出头顶和身体右侧两个位置。右侧显示敌名与生命条。头顶意图以透明底图标配数字，双剑显示本次攻击力，沙漏显示蓄势后的攻击力，暂缓图标显示一次行动。鼠标悬停或触屏按住可读格挡后的预计伤害、失守风险或暂缓说明。

设置面板的关闭按钮使用 84 × 84 设计单位的原生命中区域，覆盖 54 × 50 的按钮表面和 60 × 56 的焦点框。帮助返回设置，取消重开也返回设置。

布局与数据绑定见 `assets/prefabs/screens/BattleScreen.prefab`、`assets/prefabs/ui/HUD.prefab`、`assets/prefabs/ui/BattlePilePopup.prefab`、`assets/game/presentation/GameRenderer.ts` 和 `assets/game/presentation/cards/BattlePileModel.ts`。设置关闭与敌人锚点分别在 `assets/prefabs/ui/SettingsPopup.prefab` 和 `assets/prefabs/actors/`。

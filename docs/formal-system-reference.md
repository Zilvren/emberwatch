## 卡牌组件参考

从“战斗与卡牌”A5:I14 提取十张展示参考，保留编号、类型、独立入战斗资格、体力消耗、探索负重、使用后去向、战斗文字与制作/兑换用途。电池的体力费用为空，保留为待配置，不变成 0；绳子和现金不显示战斗费用徽标。

基础牌、武器和消耗品采用独立关键词数组，多个关键词可共存。当前 UI 可显示前三个位置，超过时保留完整说明。关键词解释依据“新增系统写这里”F1。源表的重击 5 点伤害等作为参考数值展示，没有改写现有教学卡库的数值。

展示参考位于 `assets/resources/ui/card-reference.json`，由 `tools/import-card-design-reference.cjs` 生成，明确标记为 component-design-reference。它不是可执行卡牌配置，不会让尚未实现的充能、消耗品或制作规则被静默当成已实现。

当前可玩卡库仍为 `assets/resources/data/cards.json`，新规则及本地编辑器显示“体力”费用，旧规则恢复时卡面显示对应“物资”费用。正式参考与运行卡库复用卡面结构和画风；新体力规则不表示整个正式参考卡表已经启用。实现与保存边界见 `designs/stamina-system.md`。

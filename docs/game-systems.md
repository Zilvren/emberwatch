## 游戏系统

| 系统 | 当前实现 |
| --- | --- |
| 日循环与路线探索 | 第一层两个相同补给站入口，任选一个进入同一次固定搜刮；完成后选择 A/B，分别先战斗后搜刮、先搜刮后战斗，汇合于休整，再挑战重度感染者并自动返家。教学图不提供主动撤离。 |
| 地图信息 | 主地图与房间内只读地图都只显示当前层及下一层和二者之间的连线；滚动不能看到更远节点。节点仅有图标与状态圈注，无名称、状态或悬停文字。见 `designs/ui/deck-map-components.md` 与 `map-window-verification.json`。 |
| 回合制卡牌战斗 | 手牌、抽牌堆、弃牌堆、洗牌、出牌费用、玩家结束回合及敌人意图。手牌上限 6，敌人按攻击与准备交替行动；有游荡感染者与重度感染者。 |
| 卡牌与武器 | 配置驱动的伤害、格挡、修复、装备效果；唯一武器槽；武器从下回合生成临时牌，战斗结束清除临时牌与装备状态。默认 8 种卡牌定义。 |
| 生存资源与感染临界 | 正式探索物资用于进入档位和修复，出牌使用回合体力，物资不占负重；教学兼容规则仍可出牌扣物资、物资占重。没有每日消耗。护甲为 0 后临界，再受实际伤害失败。 |
| 背包与负重 | 基础容量 30，临时溢出容量 10。新卡可进入溢出区，物资不可溢出；空间释放后按获得顺序自动转入。支持丢弃卡牌和物资；现金只能在休整时丢弃。 |
| 搜刮与战利品 | 固定和随机搜刮有入场费；卡牌与物资分别领取。战斗从当前奖励池最多展示 3 张不同牌，最多选 1 张。物资按容量截取，卡牌整张领取，允许放弃。 |
| 休整与组牌 | 非临界状态恢复最多 2 点护甲；可以选择哪些已携带卡牌参与后续战斗，或丢弃卡牌腾出空间。移出出手卡组仍占负重。 |
| 避难所整备 | 记录带回物资与卡牌，失去剩余溢出卡，解除感染临界，可选付费修复，再次出发。取消每日消耗及风险确认。 |
| 关键节点日志 | 配置声明进度次数条件和前置日志，满足后仅触发一次，保存实际日期与已读状态；普通日子不显示日志。 |
| 失败、重开与随机 | 临界时受到实际伤害失败，教学兼容情景另保留节点物资为 0 的失败检查。失败恢复初始补给、牌组和护甲；正式失败过一天且保留关键日志，教学失败仍第 1 天。明确重开才清空整份进度。 |
| 交互与表现 | 点击或拖拽出牌、手牌悬停、待机/攻击/受击等原生动画、格挡与修复反馈、伤害飘字、操作锁、背包弹窗、规则手册、操作日志、音效与静音、减少动态效果适配。 |

默认卡牌：基础攻击、基础躲避、菜刀、强化躲避、修复、重击、旧世界现金、挥砍。现金为无战斗效果的遗物，挥砍为战斗临时牌。

## 开发工具

已具备本地卡牌 Web 编辑器，使用 `npm run cards` 启动。支持新增、复制、编辑、删除卡牌，配置费用、重量、插画、颜色、效果、初始数量、固定奖励和随机奖励池，并提供卡面预览和真实 COCOS 试玩。数据保存到 `assets/resources/data/cards.json`，保存包含校验、引用保护、修订冲突检查和上一版备份。

初次试玩或游戏代码变更需要构建；仅修改卡牌数据时，保存并重开编辑器内的试玩可读取最新配置，当前对局维持原配置。新增中毒、召唤等效果需要扩展规则代码。

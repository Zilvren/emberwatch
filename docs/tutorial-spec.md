# 末日文字生存卡牌游戏：教学图原型规格

## 1. 原型目标

本原型只验证一次完整的日循环：

```text
第1天日志
→ 强制进入教学图
→ 选择路线并探索
→ 战斗、搜刮、休整
→ 自动回到避难所
→ 结算
→ 扣除每日生存物资
→ 显示第2天日志
```

显示第2天日志后，原型结束。

本阶段暂不实现：

- 正式地图；
- 多天主线；
- 完整结局；
- 支线任务系统；
- 复杂日志事件；
- 危险值和概率遇怪；
- 广告和复活机制；
- 高稀有卡牌限制。

## 2. 核心资源

### 2.1 物资点

物资点同时承担三种作用：

- 每日生存消耗；
- 战斗中打出卡牌的消耗；
- 探索时的搜刮入场费。

物资点也会占用负重：1点物资占用1点负重。

原型规则：

- 战斗卡牌消耗物资后，立即释放对应负重空间；
- 物资点归零不会立即打断当前战斗；
- 物资归零后，当前战斗继续进行，只能使用仍然支付得起的卡牌，基础牌可以继续使用；
- 战斗结束并领取奖励后，才检查物资是否为0；
- 如果仍为0，执行探索失败；
- 搜刮节点支付费用后，也要完成当前节点、领取奖励，再检查物资是否为0；
- 奖励中的物资可以把玩家从0物资状态中救回来；
- 每日生存消耗固定为1点，并且永远在结算最后执行。

### 2.2 护甲值

护甲值是主角的生命状态，最大值为10。

- 护甲大于0时，受到实际伤害会减少护甲；
- 护甲降到0不会立即失败；
- 护甲为0时，如果下一次攻击造成任何实际伤害，当前战斗立即失败；
- 如果攻击被格挡完全抵消，则不算再次受击；
- 护甲为0时，修复牌不能使用；
- 护甲为0时，即使战斗胜利，之后到达休整节点也不能恢复护甲；
- 回到避难所后，感染临界状态清除。

### 2.3 格挡

躲避牌提供临时格挡：

- 格挡只抵消当前回合的伤害；
- 回合结束时格挡清零；
- 护甲为0时，只要格挡完全抵消攻击，就不会触发失败。

## 3. 负重系统

### 3.1 负重上限

- 基础负重上限：30；
- 临时溢出上限：10；
- 临时溢出只允许存放新获得的卡牌；
- 物资点不能占用临时溢出额度；
- 卡组没有张数上限，负重决定实际能带入和带回的卡牌规模；
- 卡牌负重和卡牌使用消耗是两个独立字段。

### 3.2 卡牌风险区

- 避难所中的卡牌属于安全卡池；
- 出发时带入的卡牌进入本次探索的风险区；
- 探索中获得的卡牌也立即进入风险区；
- 主动撤离或成功结束探索后，基础负重范围内的卡牌进入安全卡池；
- 探索失败时，按失败规则永久删除卡牌；
- 玩家主动丢弃带入卡牌时，卡牌永久移除；
- 同名普通卡可以重复拥有和带入；高稀有卡的一张限制暂不实现。

### 3.3 临时溢出

- 新卡超出基础负重后，进入临时溢出区；
- 溢出区的卡牌暂时不能用于战斗；
- 后续消耗物资释放基础负重后，溢出卡按顺序自动转入可用卡组；
- 休整节点可以删除旧卡，释放空间；
- 撤离或成功结束探索时，仍在临时溢出区的卡牌失效；
- 现金牌只能在休整节点删除。

### 3.4 奖励超重

- 物资奖励可以按剩余负重截取，点击领取时自动拿到能容纳的数量；
- 卡牌不可拆分，必须整张领取或放弃；
- 玩家可以在奖励领取过程中先永久丢弃已有卡牌或物资来腾出空间；
- 未点击领取的奖励直接失去。

## 4. 战斗系统

### 4.1 回合顺序

```text
战斗开始：抽4张牌
→ 敌人展示当前意图
→ 玩家回合开始
→ 武器生成攻击牌
→ 抽3张牌
→ 玩家任意打出可支付的牌
→ 玩家结束回合
→ 敌人执行当前意图
→ 进入下一回合
```

规则：

- 不设置每回合出牌数量上限；
- 物资点是主要出牌限制；
- 手牌上限为6张；
- 未打出的手牌在回合结束时全部进入弃牌堆；
- 抽牌堆不足时，将弃牌堆洗回；
- 每场战斗结束后，手牌、抽牌堆和弃牌堆合并并重新洗牌；
- 下一场战斗不继承上一场的抽牌顺序。

### 4.2 敌人意图

教学图敌人使用固定意图顺序：

```text
攻击 → 准备 → 攻击 → 准备……
```

- 攻击：造成普通伤害；
- 准备：本回合不造成伤害，强化下一次攻击；
- 意图在玩家行动前显示；
- 玩家先行动，敌人结束时执行意图；
- 敌人被击败后不会再执行当回合意图。

### 4.3 基础牌

基础牌属于主角固有能力：

- 可以在出发时选择不带入；
- 带入后不占负重；
- 永久存在；
- 不会因探索失败被删除；
- 不进入奖励池。

| 卡牌 | 数量 | 消耗 | 效果 | 负重 |
|---|---:|---:|---|---:|
| 基础攻击 | 2 | 0 | 造成2点伤害 | 0 |
| 基础躲避 | 2 | 0 | 获得2点格挡 | 0 |

基础牌只能止损，不能稳定解决高强度敌人。

### 4.4 功能牌卡池

教学图非基础奖励卡池只有4种牌：

- 菜刀；
- 强化躲避；
- 修复；
- 重击。

同名普通卡可以重复获得。

#### 菜刀

- 类型：武器牌；
- 负重：3；
- 首次打出消耗2点物资；
- 占用唯一武器槽；
- 从下一回合开始，每回合生成1张“挥砍”；
- 当前战斗结束时解除装备；
- 武器本体回到本次探索卡组；
- 生成的攻击牌是战斗临时牌，不占负重、不进入永久卡组。

#### 挥砍

- 消耗1点物资；
- 造成4点伤害；
- 每回合开始时生成；
- 先生成，再抽3张牌；
- 如果生成后手牌超过6张，生成牌进入弃牌堆。

#### 强化躲避

- 负重：2；
- 消耗1点物资；
- 获得5点格挡。

#### 修复

- 负重：2；
- 消耗2点物资；
- 恢复3点护甲；
- 护甲为0时不能使用；
- 护甲不能超过10。

#### 重击

- 负重：4；
- 消耗1点物资；
- 造成5点伤害；
- 打出后进入弃牌堆；
- 不占武器槽；
- 不生成临时牌。

### 4.5 战斗奖励

战斗胜利后：

- 展示3张互不重复的随机卡牌；
- 最多选择1张，也可以全部放弃；
- 物资奖励单独显示、单独领取；
- 卡牌和物资都必须主动点击领取；
- 所有奖励处理结束后，返回地图页面；
- 返回地图后才检查物资是否为0。

## 5. 教学图

### 5.1 固定开局

第1天日志后，强制进入教学图，不提供留守选项。

固定配置：

- 初始物资：10；
- 初始护甲：10；
- 初始战斗卡组：7张；
  - 基础攻击×2；
  - 基础躲避×2；
  - 菜刀×1；
  - 强化躲避×1；
  - 修复×1；
- 强制携带现金牌×1；
- 玩家不能调整教学图的初始配置；
- 初始负重：10点物资＋7点功能牌负重＋10点现金负重，共27点；
- 教学图危险值关闭；
- 全程不可主动撤离。

现金牌：

- 负重：10；
- 不进入战斗抽牌；
- 不提供任何效果；
- 只能在休整节点永久删除；
- 删除后释放负重，溢出卡自动转入可用卡组。

### 5.2 路线结构

```text
入口
  ↓
固定搜刮
  ↓
路线A：敌人1 → 随机搜刮
路线B：随机搜刮 → 敌人1
  ↓
汇合：休整
  ↓
敌人2
  ↓
自动回到避难所
```

固定搜刮完成后，才显示两条路线供玩家选择。

### 5.3 固定搜刮

- 入场费：2点物资；
- 进入时立即支付；
- 固定获得4点物资；
- 固定获得1张“重击”；
- 物资和卡牌分别点击领取；
- 不触发敌人。

### 5.4 随机搜刮

- 入场费：3点物资；
- 进入时立即支付；
- 物资奖励随机为4～6点；
- 物资奖励严格大于入场费；
- 额外随机生成1张功能牌；
- 卡牌和物资分别点击领取；
- 玩家可以分别放弃卡牌或物资；
- 教学图内随机搜刮奖励保证不会因奖励过低导致资源死局。

### 5.5 休整节点

- 免费进入；
- 如果护甲从未降到0，恢复2点护甲；
- 如果护甲曾经降到0，不能恢复护甲；
- 允许自由调整本次出手卡组；
- 允许永久删除带入卡牌；
- 删除现金后，临时溢出卡自动转入；
- 不恢复物资；
- 如果触发敌人，击败敌人后仍执行休整效果；
- 教学图危险值关闭，因此不会触发额外敌人。

### 5.6 敌人1

| 属性 | 数值 |
|---|---:|
| 护甲 | 6 |
| 普通攻击 | 2 |
| 准备后攻击 | 4 |
| 战斗奖励物资 | 2 |

敌人1主要用于让玩家理解：

- 意图显示；
- 基础攻击；
- 基础躲避；
- 战斗奖励。

只使用基础牌也可以击败，但会损失一定护甲。

### 5.7 敌人2

| 属性 | 数值 |
|---|---:|
| 护甲 | 10 |
| 普通攻击 | 3 |
| 准备后攻击 | 6 |
| 战斗奖励物资 | 3 |

敌人2用于迫使玩家使用功能牌：

- 菜刀；
- 重击；
- 强化躲避；
- 修复。

敌人2的首轮手牌至少保证有1张功能牌；之后恢复正常随机抽牌。

### 5.8 教学图失败

以下情况会导致教学图失败：

- 物资在节点结算后仍为0；
- 护甲为0时受到任何实际伤害。

失败处理：

- 当前探索内容全部重置；
- 本次获得的卡牌和物资不保留；
- 不永久删除卡牌；
- 不扣除每日生存物资；
- 不进入第2天；
- 回到第1天教学图初始状态；
- 随机抽牌和随机搜刮奖励重新生成。

### 5.9 教学图成功

敌人2被击败后：

1. 领取战斗卡牌和物资奖励；
2. 返回地图页面；
3. 自动结束探索；
4. 基础负重内的卡牌和物资带回；
5. 临时溢出卡失效；
6. 战斗临时牌消失；
7. 玩家选择是否修复护甲；
8. 危险值重置；
9. 最后扣除1点每日生存物资；
10. 显示第2天日志；
11. 原型结束。

## 6. 避难所结算

回到避难所后的顺序：

1. 结算带回的卡牌和物资；
2. 清除战斗临时牌；
3. 清除武器装备状态；
4. 玩家选择是否修复护甲；
5. 护甲受损但从未降到0：支付1点物资，完全恢复到10；
6. 护甲曾降到0：支付2点物资，完全恢复到10；
7. 不修复则保留当前护甲；
8. 危险值重置；
9. 最后扣除1点每日生存物资；
10. 进入下一天日志。

修复规则：

- 只允许“支付后完全恢复”或“不修复”；
- 不支持分段修复；
- 物资不足时不能修复；
- 护甲没有损失时不收修复费用。

## 7. 随机与测试

玩家模式：

- 抽牌正常随机；
- 随机搜刮奖励正常随机；
- 战斗奖励正常随机；
- 教学失败重试时重新随机；
- 固定节点、费用和敌人行为不变。

开发测试模式：

- 支持固定随机种子；
- 可复现同一组抽牌、奖励和路线结果；
- 用于调试资源、负重、护甲和失败结算。

## 8. 原型验收标准

完成以下测试即视为教学图原型跑通：

- 第1天强制进入教学图；
- 初始7张卡、10物资、10护甲和现金牌正确加载；
- 固定搜刮能支付费用并领取固定奖励；
- 超重卡牌进入临时溢出区；
- 两条路线均可进入；
- 敌人意图按固定顺序显示和执行；
- 第一场战斗可以用基础牌完成；
- 第二场战斗能体现功能牌价值；
- 搜刮奖励和战斗奖励可以分别领取或放弃；
- 物资归零不会中断当前战斗；
- 战斗结束后奖励可以把物资从0救回来；
- 护甲归零后的感染判定正确；
- 休整能处理现金和临时溢出；
- 每场战斗结束后重新洗牌；
- 教学失败回到第1天并完全重置；
- 教学成功自动回避难所；
- 修复费用和每日1点物资消耗顺序正确；
- 最终显示第2天日志并结束原型。

## 9. 暂不解决的事项

以下内容留到教学图验证后再讨论：

- 正式地图的多层节点生成；
- 危险值具体公式和概率曲线；
- 留守事件池；
- 支线节点替换规则；
- 多天日志和固定大事件；
- 逃跑和偷窃胜利目标；
- 多武器和高稀有卡牌；
- 失败时永久删除几张卡；
- 广告救济、复活和物资补给；
- 正式地图的重复刷取与奖励成长。

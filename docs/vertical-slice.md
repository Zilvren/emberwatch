当前片段回答四个问题：游戏输入与规则是否连通；人物、背景与 UI 是否可以在同一原生画面评审；关键选择与风险是否清楚；进度恢复是否可靠。体力与进入档位已按后续要求接通并纳入验证。它不验证多日正式游戏、仓库、制作或长期平衡，也不把第 2 天终止当作正式版永久规则。

## 必须守住的品质门槛

| 维度 | 验证方式 | 不足时的处理 |
| --- | --- | --- |
| 规则与输入 | A/B 路线、真实拖牌、连续输入与命中只执行一次、奖励取消/领取 | 有关键行为失败就修复，不能以截图通过代替 |
| 结算 | 每日消耗最后执行；修复导致不足时警告、可取消也可确认 | 不因通用“安全操作”建议禁止已确认的风险玩法 |
| 持久化 | 专用 QA 浏览器保存、重载、奖励与回合状态恢复 | 不清空用户浏览器存储；不直接修改状态拼出成功流程 |
| 原生资源 | Pink 构建、主场景和动画实际运行、受保护文件对照 | TypeScript 通过不代替导入/场景/播放验证 |
| UX | 正常与 1024×768 窗口、弹窗返回、读牌、禁用原因、减少动态效果 | 明确未支持输入/平台，不推断全平台可用 |
| 美术与动作 | 全屏实际画面、局部/整体对照、正常速度与慢放时序、明确视觉认可状态 | 视觉或体验未确认时保持该门槛开放 |

# The end 当前可玩片段与品质门槛

- 项目：The end，Pink/Cocos 4.0.0-beta.1。
- 日期：2026-11-15，Asia/Shanghai。
- 状态：首次 `vertical-slice` 应用；现有教学流程作为可玩验证片段，正式版完整性与最终视觉认可分开判断。
- 归档：viking://~/resources/projects/the-end/docs/vertical-slice.md。
- 事实来源：当前原生主场景、规则/应用代码、`docs/full-game-review.md`；本轮新证据见 `docs/game-studios-evidence.json`。

## 片段范围

入口为第 1 天日志，依次完成固定搜刮、A 或 B 路线、两次战斗、搜刮/休整、返家、修复选择和最终每日消耗，到达现有第 2 天教学终点。另检查失败重试、背包和奖励确认、存档恢复。临时首战入口只供美术/交互复现，不能代替完整路线。

当前片段回答四个问题：游戏输入与规则是否连通；人物、背景与 UI 是否可以在同一原生画面评审；关键选择与风险是否清楚；进度恢复是否可靠。体力与进入档位已按后续要求接通并纳入验证。它不验证多日正式游戏、仓库、制作或长期平衡，也不把第 2 天终止当作正式版永久规则。

## 必须守住的品质门槛

| 维度 | 验证方式 | 不足时的处理 |
| --- | --- | --- |
| 规则与输入 | A/B 路线、真实拖牌、连续输入与命中只执行一次、奖励取消/领取 | 有关键行为失败就修复，不能以截图通过代替 |
| 结算 | 每日消耗最后执行；修复导致不足时警告、可取消也可确认 | 不因通用“安全操作”建议禁止已确认的风险玩法 |
| 持久化 | 专用 QA 浏览器保存、重载、奖励与回合状态恢复 | 不清空用户浏览器存储；不直接修改状态拼出成功流程 |
| 原生资源 | Pink 构建、主场景和动画实际运行、受保护文件对照 | TypeScript 通过不代替导入/场景/播放验证 |
| UX | 正常与 1024×768 窗口、弹窗返回、读牌、禁用原因、减少动态效果 | 明确未支持输入/平台，不推断全平台可用 |
| 美术与动作 | 全屏实际画面、局部/整体对照、正常速度与慢放时序、明确视觉认可状态 | 视觉或体验未确认时保持该门槛开放 |

## 本轮执行与判定

执行命令、出口状态和 9 组原生浏览器检查统一写入 `docs/game-studios-evidence.json`。运行资源与代码基线来自 `tools/game-studios/inspect.cjs`；构建使用项目自己的 `npm run build:web`。浏览器为独立的 `the-end-skills` 会话，新证据写入 `output/playwright/game-studios/`，不覆盖上一轮截图。

本轮安装适配不重新生成角色/背景/布局，也不增加玩法。实际操作与技术门槛可按新证据给出通过结论；整体画面最终认可、非待机动作流畅度和正式多日游戏门槛仍为 **NOT ASSESSED**。因此不对“正式品质片段已全面完成”给出 PROCEED。

## 后续顺序

先依据美术规范完成一项可对照的背景/接触关系修订，再逐个动作进行同造型评审；整屏布局与组件继续共同检查。每次只把已有证据支持的门槛关闭，不以增加页面、内容数量或代理数量替代品质验证。

## 2026-11-15 材质统一片段更新

美术修改没有改变正式版规则、教程成本、风险修复选择或每日消耗顺序。最终原生包与实际操作可以支持这次接入完成；整体美术最终认可、动作自然程度和正式多日完整性继续单独判断。
